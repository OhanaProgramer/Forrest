# CAD

OpenSCAD sources (`*.scad`), ready-to-print files in `stl/`, renders in `previews/`.
Printing is through the Boulder Public Library makerspace (bring the .stl).

- `forrest_fit_test_v0`: M2.5 / M2 hole-size test strip
- `forrest_jr_pi5_plate_v0`, `v1`: Pi 5 + HAT plate (v1 adds a camera wall)

On hold (2026-10-22): new mounts wait until parts are measured. Direction under
discussion: a common mounting standard (e.g. 2020 extrusion) so the sensor head
and electronics tray carry from Jr to Sr unchanged.
